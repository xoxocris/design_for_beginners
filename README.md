# Design for Beginners 🎨

A free, multi-page web resource built to help people getting started in graphic design. Created for a friend who needed a structured starting point — ended up becoming a full reference site covering design fundamentals, color theory, typography, layout, inspiration, and tooling.

**Live site:** [xoxocris.github.io/design_for_beginners](https://xoxocris.github.io/design_for_beginners)

---

## What's Inside

| Page | Description |
|---|---|
| `index.html` | Home / navigation hub |
| `basics.html` | Core design principles for beginners |
| `color.html` | Color theory — hues, contrast, palettes |
| `typography.html` | Font pairing, hierarchy, readability |
| `layout.html` | Composition, grids, spacing |
| `graphics_mockups.html` | Mockup tools and resources |
| `inspiration.html` | Curated inspiration sources |
| `resources.html` | Free tools, asset sites, learning links |
| `books.html` | Recommended reading |
| `history.html` | Design history overview |
| `about.html` | About the project |

---

## Built With

- HTML5 — semantic structure across 11 pages
- CSS3 — custom styling, layout, responsive design
- Vanilla JavaScript — interactive elements
- GitHub Pages — deployed and publicly accessible

---

## Why I Built This

A friend wanted to learn graphic design but didn't know where to start. Instead of sending a list of links, I built a structured site that organizes the fundamentals in one place — free, no signup, no paywalls. Everything on the site is a resource I've personally used or vetted.

---

## What I Learned

- Structuring a multi-page static site with consistent navigation
- Debugging layout and iframe positioning issues across pages
- Deploying and maintaining a live site via GitHub Pages
- Organizing content for a real end-user, not just for practice
